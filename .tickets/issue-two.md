# Tray single-click menu should display running time

When a user single-clicks on the green clock icon in the tray, the menu contains the running time next to the words "Timeclock: tracking (00:00:00)"

When the clock is paused and a project is still active (card removal) the current time for that project is displayed in the same menu like "Timeclock: paused (00:00:00)"

When there is no project active, there is no time.
